# Companion Icons

`saf0o-mark.svg` matches Saf0o's approved Character-flat vector master.
`src/icon.png` matches the canonical 512px desktop icon.

All icons in `src/icon.png` and `src/icons/` are generated by the desktop repo
(`node scripts/generate-companion-icons.mjs <this checkout>`) from its PNG master.
Connected icons are the colour icon; disconnected icons are the same icon in dimmed
grey. `saf0o-mark.svg` is the previous bird and is no longer used for icons.
